# Сервис бронирования репетиционных помещений

Консольное и веб-приложение для музыкантов и групп: просмотр репетиционных, проверка занятости и расчёт стоимости аренды.

## Возможности

- просмотр и поиск помещений;
- проверка вместимости;
- проверка доступности на дату и время;
- расчёт стоимости с учётом оборудования;
- создание и отмена бронирований;
- сохранение данных в JSON;
- веб-страницы помещений и бронирований.

## Предметная область

- `Room` и наследник `RehearsalRoom` — помещение и репетиционная с комплектом оборудования;
- `Musician` — музыкант или группа;
- `Booking` — бронирование помещения музыкантом на дату, время и число часов.

Время хранится в бронировании: дата, время начала и продолжительность.

## Структура проекта

- `main.py` — консольное меню;
- `models/` — классы предметной области;
- `storage.py` — загрузка и сохранение JSON;
- `utils.py` — ввод и вспомогательные функции;
- `data/` — JSON-файлы;
- `tests/` — тесты pytest;
- `manage.py`, `rehearsal/` — Django-проект;
- `homepage/`, `rooms/`, `bookings/` — приложения и шаблоны;
- `templates/base.html` — общий каркас страниц;
- `homepage/static/homepage/` — собственные CSS, JavaScript и логотип.

## Требования

- Python 3.12;
- зависимости из `requirements.txt`: Django 5.2, pytest, flake8.

Установка:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
```

## Запуск консольной программы

```bash
python main.py
```

## Запуск веб-приложения

```bash
python manage.py runserver
```

Страницы: `/`, `/rooms/`, `/rooms/1/`, `/bookings/`, `/bookings/1/`.

## Проверки

```bash
pytest -v
flake8 . --extend-exclude=venv
python manage.py check
```
