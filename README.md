# Сервис бронирования репетиционных помещений

## Назначение

Приложение предназначено для бронирования репетиционных помещений музыкантами. Пользователь может просматривать информацию о помещении, проверять его доступность на выбранное время и рассчитывать стоимость аренды.

## Целевая аудитория

- Музыканты
- Музыкальные группы
- Администраторы репетиционных студий

## Предметная область

Система предназначена для организации процесса бронирования репетиционных помещений. Она позволяет хранить информацию о помещениях, музыкантах, времени бронирования и управлять заявками на аренду.

## Основные сущности

- Музыкант
- Помещение
- Время
- Бронирование

## Основные функции

- Просмотр информации о помещении
- Проверка доступности помещения на выбранное время
- Расчет стоимости бронирования

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
